# SoundBridge Blocks

Companion plugin for the SoundBridge Core WordPress theme.

## Responsibilities

### Custom post types
- Programs
- Events
- Music Directory

### Taxonomies
- Program Types
- Event Types
- Directory Categories

### Custom Gutenberg blocks
- Hero
- Split Content
- Card Grid
- Stats
- Call to Action
- FAQ
- Program Grid
- Event Grid

The plugin intentionally contains content architecture rather than theme presentation, so Programs, Events, Directory entries, and block definitions remain portable if the visual theme is replaced.
