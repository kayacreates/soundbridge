# SoundBridge Core

Custom WordPress theme for SoundBridge presentation and templates.

## Responsibilities

- Global header/footer and navigation
- `theme.json` design tokens and editor settings
- Front-end CSS/JS
- Page, archive, and single templates
- Presentation for Program, Event, and Music Directory content

## Companion plugin

Install and activate **SoundBridge Blocks** alongside this theme. The plugin owns the site's structured content and custom Gutenberg blocks so content remains available even if the theme changes later.
